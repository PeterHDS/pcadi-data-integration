# Project updates

This page records substantive changes to PCADI's source support, analytical contracts and validation capabilities.

## Current publication baseline

- Configurable SQL and Python practice-month integration for OCS, GPAD, CBT and registered-patient data.
- Source-led, coverage-preserving and matched analytical designs with explicit retained populations.
- Verified April 2025 to March 2026 reference application.
- A 6,067-practice national annual matrix with separate GPAD `1 day` and `2 to 7 days` features.
- Nested CBT evidence cohorts containing 3,020 and 1,456 practices with exact inherited parent values.
- Deterministic one-, three-, twelve- and twenty-four-month synthetic demonstrations.
- Machine-readable source lineage, validation gates, output contracts and checksums.

Future entries will describe material additions such as a supported source-period extension, a validated source-schema change or a new integration capability.
