# April 2025 to March 2026 verified reference application

This page documents the official prepared data and frozen outputs included with
PCADI. It is one verified application of the reusable pipeline.

## Observation period

The analytical window covers observations from 1 April 2025 through 31 March
2026. Publication files released later may supply or revise observations
inside that window; the publication month is recorded separately from the
observation month.

## Included sources

The application uses selected official NHS England publications for:

- Online Consultation Systems (OCS);
- General Practice Appointments Data (GPAD);
- Cloud Based Telephony (CBT); and
- registered-patient counts carried by the validated monthly source contract.

ODS practice codes provide the organisational identity used for linkage. They
are not treated as an activity source. The exact selected publication members,
release vintages, observation-month ownership and source checksums are in
[`reference-release/manifests`](../../reference-release/manifests) and the
[source register](../../validation/authoritative_source_register.csv).

## Preparation boundary

Raw NHS downloads and the large working database are not distributed in this
repository. The public evidence starts at complete SQL, prepared-source
contracts, source manifests, compact outputs, data dictionaries and validation
registers.

The full source reconstruction requires the 21 exact selected source CSVs. The
compact validation route checks frozen outputs without rebuilding the large
source database.

## Annual matrices

| Matrix | Rows | Columns | Numerical features | Purpose |
|---|---:|---:|---:|---|
| `primary_practice_access_clustering_matrix.csv` | 6,067 | 15 | 14 | National annual OCS-GPAD reference matrix |
| `cbt_inbound_sensitivity_clustering_matrix_17_features.csv` | 3,020 | 18 | 17 | CBT inbound evidence sensitivity cohort |
| `cbt_outcomes_sensitivity_clustering_matrix_21_features.csv` | 1,456 | 22 | 21 | CBT outcome-complete sensitivity cohort |

Every matrix contains one unique standardised practice code and no missing,
non-numeric or non-finite modelling value. The identifier is retained for
traceability and is not a numerical feature.

The GPAD booking-delay composition retains separate `same day`, `1 day`,
`2 to 7 days`, `8 to 14 days` and `over 14 days` features. The 3,020-practice
cohort is nested inside the 6,067-practice matrix. The 1,456-practice cohort is
nested inside both. Shared parent values are inherited exactly.

## Validation

Run:

```powershell
python automation/pipeline_cli.py validate-reference `
  --restore-missing `
  --output work/reference_validation.csv
```

This checks all 14 registered reference outputs. If release-only files are
absent, the command retrieves
`PCADI_REFERENCE_OUTPUTS_APR2025_MAR2026.zip` from the
`reference-apr2025-mar2026` release, verifies its exact size and SHA-256
checksum, restores `outputs/<filename>` members and validates each CSV.

Complete file fingerprints are recorded in the
[authoritative output manifest](../../validation/authoritative_output_manifest.csv).
Feature definitions are in the
[feature dictionary](../../reference-release/documentation/FEATURE_DICTIONARY.md).
The [analytical contract and lineage](../audits/ANALYTICAL_CONTRACT_AND_LINEAGE.md)
documents annual formulas, cohort rules and inherited-value checks.

## Analytical use

The annual matrices are prepared inputs for downstream analysis. PCADI does not
run clustering as part of integration or reference validation. Any modelling
method, preprocessing decision and sensitivity analysis must be documented
separately.

## Interpretation boundaries

The outputs contain recorded activity, not patient-level pathways:

- activity is not total demand;
- appointments are not total workload;
- calls are not patient journeys;
- missing is not zero;
- profiles are not performance ranks; and
- association does not demonstrate causation or channel substitution.

The reference application supported an MSc research project. Its academic role
and examiner route are documented in [Research context](../research-context.md).
PCADI can be reused independently of that study.
