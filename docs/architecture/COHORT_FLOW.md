# Annual cohort flow

![PCADI annual cohort flow](../assets/pcadi-cohort-flow.svg)

The fixed April 2025 to March 2026 build observes 6,210 annual OCS practices
and 6,184 annual GPAD practices. Source completeness, reconciliation and
positive month-matched denominator rules retain 6,130 practices before the
final activity-total rule. Sixty-three documented exclusions leave 6,067
practices in the national matrix.

Valid complete CBT evidence narrows the same population. The inbound matrix
contains 3,020 practices. The outcome-complete matrix contains 1,456 practices
inside that inbound cohort.

These restrictions reflect evidence availability. The CBT populations are not
random samples and should not be described as nationally representative
replacements for the 6,067-practice matrix.
