# PCADI v2.0.0 release notes

PCADI v2.0.0 corrects the public annual modelling interface and reorganises the
documentation around analytical questions.

## Analytical interface

- The national annual matrix contains 6,067 practices and fourteen numerical
  features.
- GPAD `1 day` and `2 to 7 days` shares remain separate.
- The CBT inbound matrix contains 3,020 practices and seventeen numerical
  features.
- The CBT outcome-complete matrix contains 1,456 practices and twenty-one raw
  numerical features.
- Shared parent values are checked for exact inheritance.

## Documentation

- Public design names describe the retained population and purpose.
- Individual design pages state grain, join key, use, limitation and required
  validation.
- The README routes examiners, analysts, learners, reviewers and maintainers.
- Architecture and cohort-flow figures include text equivalents.

## Validation

The release locks exact schemas, dimensions and SHA-256 checksums. Synthetic
tests keep the two booking bands deliberately unequal, check configurable
periods and verify that CBT matrices inherit unchanged parent values.

See the [migration note](MIGRATION_13_TO_14_FEATURES.md) for the controlled
change from v1.
